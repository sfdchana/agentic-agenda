# Day 6 — LangChain: set up Python + a first chain

- [ ] Done

**After this you should know:** how to stand up a Python AI environment and make your first
LangChain model call — the new stack, hello-world'd.

## 📖 Read (~15 min)
[LangChain — Introduction](https://python.langchain.com/docs/introduction/). Get: what
LangChain is (a toolkit for composing LLM calls) and its core pieces.

## 🛠️ Build (~20 min)
Create a Python venv beside your Node repo (e.g. `classifier/`), install
`langchain langchain-anthropic pydantic`, and make a hello-world call to Claude through a
chain. Just get it running.

## 🤖 Claude-craft (~10 min)
Read the [Model Context Protocol intro](https://modelcontextprotocol.io/introduction);
list which connectors are available to you.
