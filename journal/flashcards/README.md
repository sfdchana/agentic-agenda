# Flashcards

Weekly consolidation — one file per week (`week-01.md`, `week-02.md`, …), built
from the *actual concepts* learned that week, not just raw notes.

**How to review:** read the question, cover the answer, say it out loud, then
check. The ones you miss are the ones worth re-reading (or dropping into Anki in
your own words — the rewriting is the encoding).

**Cadence:** made at the end of each week (Friday-ish). A quick pass over the
current week + a skim of prior weeks keeps it in memory.
