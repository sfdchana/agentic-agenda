# job-listing-collector

A running log of jobs worth targeting for the fashion-tech / data-AI move.
**Populated by a skill** (weekly, or whenever I prompt it) — not hand-hunted.

Each entry breaks a job into: how well I match, what I already have, and what I'd
need to build. Over time this doubles as a **gap map** — the "skills to build"
column tells me what to prioritize in the plan, and the match % should climb as
the months go on.

- `jobs.md` — the running list + the entry template.

Not for applying yet (the search is ~12–18 months out). This is early
reconnaissance: knowing what the target roles actually ask for, so the projects
and learning aim at real requirements instead of guesses.
