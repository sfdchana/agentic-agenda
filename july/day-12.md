# Day 12 — Classes, decorators, context managers

- [ ] Done

**After this you should know:** Python OO plus the two constructs Apex doesn't have: decorators and `with`.

## Do (~1 hr)
Write a class; write a simple decorator (e.g. timing or logging); use a context manager (`with open(...) as f:`).
Analogy: a decorator ≈ an annotation that wraps behavior; `with` ≈ guaranteed cleanup (like a `finally`).

## 3 flashcard ideas
- What does a decorator do?
- What does `with` guarantee?
- Python `__init__` vs an Apex constructor.
